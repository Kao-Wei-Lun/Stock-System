# 資金熱力圖 (ECharts) 美化與互動體驗升級計畫

讓「台股資金熱力圖」的操作與視覺體驗盡可能貼近「TradingView 美股熱力圖」，包含點擊板塊放大、返回上一層，以及顏色與邊框的精緻化。

## 1. 視覺美化 (TV 樣式對齊)
TradingView 著名的熱力圖風格有以下幾個特徵，我們將依此改寫 ECharts 設定：
- **極簡邊框與間距**：
  - 取消板塊之間過粗的線條，改為極細的 1px 間距，大板塊（產業）間距改為 2px-3px。
  - 將背景改為純淨的 `#131722` 或是與網頁一致的 `transparent`。
- **標準化漲跌色彩 (Color Palette)**：
  - 強跌 (≤ -3%)：`#f23645` (TV 標準紅)
  - 微跌 (< 0%)：`#f7525f` (TV 淺紅)
  - 平盤 (0%)：`#2a2e39` (TV 灰)
  - 微漲 (> 0%)：`#22ab94` (TV 淺綠)
  - 強漲 (≥ 3%)：`#089981` (TV 標準綠)
  - *(備註：由於台股習慣「紅漲綠跌」，所以這邊會對調為：強漲紅 `#f23645`，強跌綠 `#089981`)*
- **標籤字型優化 (Typography)**：
  - `upperLabel` (產業標題)：調高至 `28px`，設定字重為 bold，並給予深色底色，讓它看起來像可以點擊的 Header。

## 2. 板塊點擊放大與層級切換 (Drill-down Experience)
ECharts 本身支援 `nodeClick: 'zoomToNode'`，代表點擊父節點 (也就是 `upperLabel` 產業標題框) 時，會放大該產業至全視角。為了讓這項功能更清晰：
- **開啟 `roam: true`**，允許滑鼠滾輪縮放與拖曳。
- **美化 Breadcrumb (麵包屑導覽)**：這就是「回上一步顯示所有產業」的功能。當放大進入某產業後，底部/頂部會出現導覽列。我們將 Breadcrumb 的按鈕美化成 TV 的返回按鈕風格，設定深色底與發光字體。
