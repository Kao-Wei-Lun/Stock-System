# 本地通知中心浮動版面修改規畫

## 1. 修改目標

目前通知中心固定在右下角，只能收合及垂直調整高度。當頁面右下方有五檔、狀態列、
表格操作或重要圖表時，通知中心會遮住內容，使用者也無法選擇較合適的位置。

本次修改目標：

1. 桌面版通知中心在展開及縮小狀態都可由專用把手拖曳。
2. 提供左上、右上、左下、右下四個快速停靠位置。
3. 記住位置、面板高度及收合狀態，重新整理後恢復。
4. 視窗縮放或解析度改變後，面板必須留在可視範圍。
5. 提供一鍵重設，不讓錯誤位置永久卡住。
6. 手機與窄螢幕維持底部抽屜，不啟用自由拖曳。
7. 不影響通知篩選、搜尋、標記已讀、開啟商品、日誌與模板等既有功能。

## 2. 現況與問題

- 容器使用 `position: fixed; right: 18px; bottom: 18px`。
- `z-index: 30` 低於部分浮動工具，通知中心可能被其他元件覆蓋。
- 面板只支援 `resize: vertical`，沒有位置狀態。
- 收合狀態、位置與高度都不會在重新整理後保留。
- 現有手機規則只調整寬度與高度，沒有處理桌面自訂位置可能殘留的問題。

## 3. 版面狀態模型

使用版本化、僅限瀏覽器本機的 layout state：

```json
{
  "version": 1,
  "anchor": "bottom-right",
  "x": null,
  "y": null,
  "panelHeight": null,
  "collapsed": true
}
```

`anchor` 允許：

- `top-left`
- `top-right`
- `bottom-left`
- `bottom-right`
- `custom`

儲存於 `localStorage`，key 為
`quantvision:notification-center-layout:v1`。資料不得包含通知內容、ticker、資產或帳號。
讀取失敗、格式錯誤或版本不符時，回到右下角收合狀態。

## 4. 詳細修改

### Phase A：純版面工具

新增可測試的浮動面板工具，負責：

- 驗證與正規化持久化資料。
- 將四角停靠狀態映射為穩定樣式。
- 將自訂座標限制在目前 viewport。
- 根據面板尺寸重新校正位置。
- 安全讀寫及清除 layout state。

驗收：

- 損壞 JSON 不造成畫面白屏。
- 無效 anchor、負座標、過大座標與不合理高度都會被修正。
- storage 不可用時仍能正常使用通知中心。

### Phase B：桌面拖曳與快速停靠

通知中心加入：

- 專用拖曳把手，只有把手能開始拖曳。
- 縮小狀態使用獨立把手，拖曳不會誤觸展開按鈕。
- Pointer Events 與 pointer capture，支援滑鼠及觸控板。
- 拖曳開始時由目前實際位置切換為 `custom`。
- 拖曳過程只更新 fixed 容器的 `left/top`，不改動頁面文件流。
- 左上、右上、左下、右下快速停靠按鈕。
- 重設按鈕，恢復右下角與預設高度，保留目前展開／收合狀態。
- 鍵盤方向鍵微調位置，保留基本可及性。

驗收：

- 從四個方向拖曳後仍可操作搜尋框與通知按鈕。
- 縮小後可重新定位，拖曳過程不會展開面板。
- 拖曳不會誤觸縮小、已讀、日誌或商品操作。
- 快速停靠後位置正確，且重新整理後仍保留。
- 重設後回到右下角。

### Phase C：尺寸、邊界與響應式

- 使用 `ResizeObserver` 記住桌面面板高度。
- 視窗 `resize`、`orientationchange` 及 `visualViewport.resize` 時重新限制座標。
- 桌面面板最大高度改為可視區域扣除安全間距。
- 一般內容之上、Modal／全螢幕元件之下的 z-index。
- `max-width: 640px` 時強制底部抽屜：
  - 忽略桌面自訂 `x/y`。
  - 禁用並隱藏拖曳／四角停靠控制。
  - 不套用桌面保存高度。
  - 清單仍可獨立上下捲動。
- 回到桌面寬度時恢復先前桌面位置。

驗收：

- 1280×720、1920×1080 及窄螢幕下不超出 viewport。
- 面板調高後，通知清單仍能捲動。
- 從大螢幕切到小螢幕再切回，不遺失桌面位置。
- 搜尋框取得焦點或手機鍵盤出現時不把面板推到畫面外。

### Phase D：測試與最終 Gate

單元測試：

- 四角停靠樣式。
- 拖曳進入 custom 模式。
- 座標邊界限制。
- 鍵盤移動。
- 收合、展開與面板高度保存。
- storage 損壞與 storage 拒絕存取。
- 重設版面。
- 手機版停用拖曳。
- 既有通知篩選與操作事件全部保留。

瀏覽器驗收：

- 在總覽與終端開啟通知中心。
- 快速停靠四角。
- 拖曳後不遮住原本位置的重要內容。
- 重新整理後恢復位置。
- 縮小視窗後仍在可視範圍。
- 手機 viewport 顯示底部抽屜。

最終 Gate：

1. NotificationPanel 專屬測試全數通過。
2. 前端完整 Vitest 全數通過。
3. Production build 通過。
4. Bundle budget 不放寬且通過。
5. Production E2E 全數通過。
6. `git diff --check` 通過。
7. `.codex/config.toml`、通知內容與任何個人資料不得進入 commit。

## 5. 回滾

- UI 可先移除拖曳與位置工具列，保留原通知資料與事件 API。
- layout storage 是純前端偏好，不涉及資料庫 migration。
- 舊版程式會忽略新的 localStorage key，不影響通知資料。
- 若保存資料異常，使用「重設位置」或刪除該 layout key 即可恢復右下角預設。
