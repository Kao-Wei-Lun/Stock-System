# 🧪 測試品質分析

請扮演 **Testing & QA Engineer（測試工程師）** 角色，對 QuantVision Pro 的測試品質進行深度分析。

## 分析步驟

1. **盤點後端測試**
   - 列出 `backend/tests/` 下所有測試檔案
   - 統計每個測試檔的測試案例數量
   - 分析每個測試檔對應到的功能模組
   - 找出沒有對應測試的後端模組

2. **盤點前端測試**
   - 列出 `frontend/src/` 下所有 `.spec.js` 檔案
   - 統計每個測試檔的測試案例數量
   - 找出沒有對應測試的前端組件

3. **測試覆蓋率分析**
   - 建立「模組 → 測試檔」對應矩陣
   - 標記完全無測試的模組為 🔴
   - 標記有測試但覆蓋不足的模組為 🟡

4. **回測引擎前視偏誤檢查** ⚠️ 重要
   - 讀取 `backend/backtest_engine.py`
   - 檢查策略邏輯是否在計算訊號時使用了未來資料
   - 檢查是否使用了 look-ahead 的 pandas 操作（如未來日期的 shift）
   - 讀取 `backend/tests/test_backtest_engine.py`，檢查是否有測試防止前視偏誤

5. **驗收要求覆蓋度**
   - 讀取 `docs/quantvision-product-spec.md` 的 §15（測試與驗收規格）
   - 列出規格中定義的所有測試要求
   - 比對實際測試是否覆蓋這些要求

6. **測試品質評估**
   - 檢查測試是否有適當的 setup/teardown
   - 檢查是否有 mock 策略避免依賴外部 API
   - 檢查邊界條件測試（空資料、錯誤輸入、超時等）
   - 檢查是否有整合測試（跨模組流程）

7. **嘗試執行測試（如可行）**
   - 嘗試執行 `cd backend && python -m pytest --tb=short -q`
   - 嘗試執行 `cd frontend && npx vitest run --reporter=verbose`
   - 記錄成功/失敗的測試案例
